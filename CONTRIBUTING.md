# Contributing

- New motion patterns go in `.agents/skills/remotion-motion-graphics/references/motion-patterns.md`.
- Palettes, type and pacing go in `references/design-rules.md`.
- Keep patterns real Remotion + TypeScript, deterministic and `fps`-derived (see the 10 rules in `SKILL.md`).
- Scripts must stay cross-platform Node (no bash-only syntax) so they work in PowerShell.
- Keep `SKILL.md` lean; move bulk text into `references/`.
- If you add a pattern, show that it renders (attach a frame or clip).
- One concern per PR.

Maintained by umorfaruksupto. Open an issue or pull request at https://github.com/luminexlabs-io/antigravity-remotion-skill.
